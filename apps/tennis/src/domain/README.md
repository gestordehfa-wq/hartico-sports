# Tennis domain

Reglas puras y tipos propios para temporadas, jugadores, torneos/ediciones,
inscripciones, cuadros, partidos, sets, ranking estacional, H2H y estadísticas.
No importa ni adapta entidades de Racing o Football Lite.

`model.ts` define contratos; `rules.ts` implementa cálculos sin React o
Supabase; `rules.test.ts` prueba el dominio.
